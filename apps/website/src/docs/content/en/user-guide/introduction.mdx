---
title: Using Papra
description: Learn to archive, organize, and find your documents with Papra.
---

Papra helps you archive your documents, organize them with tags, and find them again with search.

The user guide is for people using either Papra Cloud or a self-hosted instance. It covers everyday document workflows, search, tagging and automation, importing documents, and working with others in an organization.

Detailed guides will be added as the documentation is migrated.
