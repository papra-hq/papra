This section explains how Papra works and why it behaves the way it does. It is for anyone who wants to understand their archive, not just developers.

Topics include preserving original documents, document deduplication, document processing, and the organization deletion and purge lifecycle.

These explanations will be added as the documentation is migrated. Instructions for using features belong in the user guide; deployment and configuration instructions belong in self-hosting.
