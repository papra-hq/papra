---
title: Installing Papra on Umbrel
description: Install Papra on your Umbrel node.
---

You can install Papra on your Umbrel simply by using the Umbrel App Store. This method is recommended for users seeking a production-ready setup with minimal maintenance overhead.

## Install Papra app

1. Open your Umbrel dashboard. See [Connecting to your Umbrel](https://umbrel.com/support/getting-started/connecting-to-your-umbrel) if you need help connecting.
2. Click on the **App Store** link.
3. Search for **Papra** in the search bar.
4. Click on the **Install** button to start the installation process.
5. Once the installation is complete, you can access Papra from your Umbrel dashboard.
